REST REFERENCE

PinScrap API

Dashboard requests go to the PinScrap service running this page.

GET

Search pins

/api/search?q=architecture&limit=60&type=all&filterGenAi=true

Returns Pinterest pin metadata and available image or video URLs.

GET

Download an asset

/api/download?url={pinimg_url}&name={filename}

Streams an individual Pinterest image or video through the media proxy.

GET

Download a ZIP

/api/zip?q=architecture&limit=60&type=all

Packages downloadable search results into a ZIP archive.

GET

Health check

/health

Reports API availability, uptime, and cached search count.
